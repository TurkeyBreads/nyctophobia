# Nyctophobia

## Game Theme

##### The game is set inside Nyctophobia, a strange underground maze where darkness behaves like a living force. The tone is eerie and disorienting rather than purely grim — room descriptions emphasize fading light, distorted shadows, distant sounds, and things that seem to move whenever the Player looks away. Familiar dungeon elements become unsettling: torches burn backwards, corridors seem longer in darkness, and doors occasionally lead somewhere different from where they should.
##### Mechanically, it is a classic hunt-the-monster maze: the Player explores a small network of interconnected Rooms, collects a weapon and several useful items, and eventually confronts Nyctophobia's central creature, the monster responsible for the dungeon's shifting darkness. Smaller creatures and environmental hazards provide optional encounters along the way, allowing the Player to learn the combat and item systems before reaching the main confrontation.
